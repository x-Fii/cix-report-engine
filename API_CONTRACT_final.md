## 1. Auth & Identity Management
*Leverages Firebase/Supabase solely as an Identity Provider (IdP) for sending OTPs to corporate emails. The Python backend intercepts the JWT, validates the signature cryptographically, and maps the verified email to the MariaDB `users` table for Role-Based Access Control (RBAC).*

* `POST /auth/otp-request` — Triggers OTP. Fails immediately if domain `!= @click-ix.com`.
  ```json
  { "email": "azam@click-ix.com" }

```

* `POST /auth/login` — Exchanges OTP for corporate JWT.
```json
{ "email": "azam@click-ix.com", "otp": "482015" }

```


* `GET /auth/me` — Returns active user context, resolving MariaDB `user_roles`.
* `POST /auth/refresh` — Rotates expired IdP session tokens.

### Catalog Items

* `GET /catalog/items?type=hardware|service|bulk`

## 4. Procurement & AutoCount Linkage

* `GET/POST /procurement/grn` — Goods Receiving. **Rule:** Serialized hardware transitions state `inbound → unassign`. Bulk items are appended mathematically to `inventory_stock.qty`.
* `GET /procurement/document-references` — Central hub for Finance tracking. Maps the internal `QT-` and `DO-` flow to the external `sales_invoice` and `supplier_invoice` generated by AutoCount.

## 5. Field Execution (Ops)

### Delivery Orders (The Warehouse Departure)

* `GET /operations/delivery-orders/{do_no}` — Returns full DO metadata with deeply nested structural `outlet` context (Name, PIC, Address, Contact) for seamless mobile pre-fills.
* `POST /operations/delivery-orders` — **Logic Trap Check:** Any SKUs passed in the `assigned_pc_skus` array must have a MariaDB state of `unassign`. Bulk items are pushed to the `items` array directly.
* `POST /operations/delivery-orders/{do_no}/split` — Handles partial approvals. If a client rejects 2 items at the door, Vicky triggers a split, creating a child DO and leaving the active DO perfectly balanced with the truck stock.
* `GET /operations/delivery-orders/{do_no}/pdf`

### Service Reports (The iPad Sign-Off Execution)

Submitting an approved sheet processes the operational logic paths as a single execution block to maintain structural database data mapping.

* `POST /operations/service-reports`
* **Serialized Logic:** Items in `hardware_installed` transition state to `deployed`. Items in `hardware_removed` transition to `unassign`, **UNLESS** `is_faulty=true` is flagged by the technician, which intercepts the loop and forces the state to `to be disposed`.
* **Bulk Logic:** Consumed bulk items directly subtract from `inventory_stock.qty`.
* **Photo Rules:** The request payload MUST contain `before_photos_json` and `after_photos_json` containing the PK IDs from the `/uploads` endpoint.
* **Trigger Chain:** Successfully committing a Service Report automatically invokes the hidden DO Sign-Off function, resolving the parent DO state to `delivered`.


* `GET /operations/service-reports/{sr_no}/pdf` — Compiles the `Template_-_Service_Report.docx` structural equivalent for client email dispatches.
